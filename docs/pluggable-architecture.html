normalized event schema v1 — the real coupling point

header

19-byte common header. Mandatory. Byte-identical across correct adapters — disagreement = broken adapter.

decoded

Best-effort canonical decode: tables, row values, SQL. Adapters fill what they can.

native

Adapter-specific rendering, opaque. Preserved verbatim — this is what the diff view compares.

Core (Go binary)

Indexer

Streams events from the roles.indexer adapter. Metadata only — no row values. On growth it true-seeks from the committed boundary (last_indexed_offset) and appends only the new tail; positions use a running byte accumulator, so > 4 GiB files (uint32 end_log_pos wrap) index correctly.

SQLite index

files · events · txns · tables · anomalies · decode_errors
~5% of binlog size. Records which adapter built it. A post-index anomaly engine flags oversized/long txns and the 4 GiB position wrap.

Diff engine

Lazy, per-event, at click time: runs all roles.diff adapters at one offset, aligns by schema layer, flags disagreements.

Hex service

Adapter-independent. Raw bytes read straight from file via offset, header fields annotated from byte layout.
